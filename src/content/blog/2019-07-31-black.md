今天我们正式采用了 Python 代码格式化工具 [Black](https://black.readthedocs.io)。所有代码已使用 Black 进行格式化，所有未来的贡献都将经过检查，以确保它们已使用 Black 格式化。

作为采用 Black 的一部分，flake8 和 pylint 中的所有样式检查均已禁用。

为了确保您在提交更改时所有文件都符合 Black 格式，我们使用了 [`pre-commit`](https://pre-commit.com/)。该钩子会自动安装到新的开发环境中（作为 `script/setup` 的一部分）。

如果您已有开发者安装环境，请在您的虚拟环境中运行：

```
pip install pre-commit
pre-commit install
```

`pre-commit` 不会更改您的文件，只是确认更改的文件已由 Black 格式化。我们建议您将编辑器设置为在保存时自动使用 Black 格式化文件。各种编辑器的相关说明可以在[这里](https://black.readthedocs.io/en/stable/integrations/editors.html)找到。
