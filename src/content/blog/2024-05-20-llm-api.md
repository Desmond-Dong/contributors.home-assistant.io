自从我们在“语音之年”（Year of the Voice）活动中将 LLM 引入 Home Assistant 以来，我们收到了许多请求，希望能够允许 LLM 与 Home Assistant 进行交互。现在，通过向 LLM 开放 Home Assistant API，这已成为可能。

Home Assistant 将内置一个 Assist API，它所遵循的功能和已公开的实体（entity）与内置对话代理（conversation agent）所能访问的相同。

与 LLM 交互的集成（integration）应更新其集成以支持 LLM API。

自定义集成作者可以创建自己的 LLM API，以便为 LLM 提供对 Home Assistant 更高级的访问能力。

更多信息请参阅 [LLM API 文档](/core/internals/llm-api/)，以及关于如何在您的集成中使用 LLM API 的[这个示例拉取请求](https://github.com/home-assistant/core/pull/117644)。
