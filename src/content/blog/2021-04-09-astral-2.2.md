我们最近合并了一个[拉取请求（pull request）](https://github.com/home-assistant/core/pull/48573)，将 Home Assistant Core 中使用的 astral 库版本升级到 2.2。此更改将随 Home Assistant 2021.5 一起发布。这是 Astral 的一个主要版本升级，包含一些破坏性变更（breaking changes），因此我们更新了依赖于 astral 的内置辅助元素（helper）和集成（integration）。这对我们的太阳辅助元素（sun helper）造成了几个破坏性变更。

维护使用太阳辅助元素或直接使用 astral 库的集成的自定义集成作者，应查看这些破坏性变更，并在需要时更新其自定义集成。

太阳辅助元素更改了 `get_astral_location` 和 `get_location_astral_event_next` 的签名，以包含一个 `elevation` 参数。此外，`get_astral_location` 的返回值也已更改为包含海拔（elevation）的元组。

```py
@callback
@bind_hass
def get_astral_location(
    hass: HomeAssistant,
) -> tuple[astral.location.Location, astral.Elevation]:
    """Get an astral location for the current Home Assistant configuration."""

@callback
def get_location_astral_event_next(
    location: astral.Location,
    location: astral.location.Location,
    elevation: astral.Elevation,
    event: str,
    utc_point_in_time: datetime.datetime | None = None,
    offset: datetime.timedelta | None = None,
) -> datetime.datetime:
    """Calculate the next specified solar event."""
```

有关更多详情，请参阅 [`astral` 的更新日志（changelog）](https://github.com/sffjunkie/astral/blob/master/ChangeLog.md#22---2020-05-20)。
