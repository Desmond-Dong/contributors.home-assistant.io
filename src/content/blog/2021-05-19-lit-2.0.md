我们将前端升级为使用 Lit 2.0，这是 `LitElement`（3.0）和 `lit-html`（2.0）的一次重大版本升级，二者今后将以 [Lit](https://lit.dev) 之名共同发展。

此次升级带来了大量出色的[改进](https://lit.dev/blog/2021-04-21-lit-2.0-meet-lit-all-over-again/)，但也包含一些破坏性变更。

如果您开发过自定义卡片（custom card）或视图，并且使用了我们组件中的 `LitElement` 和 `lit-html`，那么您的组件将在下一个版本（2021.6）中使用 Lit 2.0。如果您不确定自己是否使用了我们组件中的 `LitElement`，您的代码可能类似于这样：

```ts
const LitElement = Object.getPrototypeOf(customElements.get("ha-panel-lovelace"));
const html = LitElement.prototype.html;
const css = LitElement.prototype.css;
```

这并不是推荐的做法，我们建议您将 Lit 打包进您的组件中，或者像这个[示例](/frontend/custom-ui/card/)那样从 `unpkg.com` 或其他来源导入。这样您的卡片就不会依赖于 Home Assistant 随附的 Lit 版本。

其中一项变化是，`shadowRoot` 的创建不再在构造函数中完成，而是在首次更新之前进行。这意味着如果您直接操作 DOM（例如使用查询选择器），就不能再假设 `shadowRoot` 始终可用。

有关所有变更，请查阅 Lit 文档中的[升级指南](https://lit.dev/docs/releases/upgrade/)。

我们预计大多数卡片在 Lit 2.0 上都能正常运行，但仍请自定义卡片开发者确保兼容性。您可以使用当前的 Home Assistant dev 版本或 Home Assistant nightly 版本进行测试，两者目前都使用 Lit 2.0。
