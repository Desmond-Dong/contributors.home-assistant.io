名称和标志是品牌中最显眼的部分。本页介绍如何书写名称、标志的工作方式，以及哪些用途需要获得许可。

## 书写名称

- **完整书写 "Home Assistant"**，H 和 A 大写，中间有一个空格。绝不要写成 "HA"、"HASS" 或 "Home-Assistant"。这适用于所有地方：文档、界面、博客文章以及本网站。
- **不要使用旧名称。** "Hass.io" 现在就是 Home Assistant，"HassOS" 则是 Home Assistant Operating System。[home-assistant.io](https://github.com/home-assistant/home-assistant.io) 的自动检查会标记出这两者。
- **不要翻译它。** 在任何语言中，名称都保持为 "Home Assistant"。请参阅[翻译规则](/translate/reference/rules/)。

完整的软件套件称为 Home Assistant。其中最主要的软件，即 Python 应用程序，称为 Home Assistant Core。这个命名始于 2020 年 1 月，当时调整了品牌命名，使项目的各个部分更容易区分。

名称有时会变化。Home Assistant Cloud 于 2026 年 10 月更名为 Home Assistant Link。在代码中，它仍然是 `cloud` 集成（integration）。

## Open Home Foundation

Home Assistant 由非营利组织 [Open Home Foundation](/glossary/open-home-foundation/) 所有。[home-assistant.io](https://www.home-assistant.io/) 的页脚是这样表述的："Home Assistant is a project from the Open Home Foundation."

基金会的商业合作伙伴，例如 [Nabu Casa](/glossary/nabu-casa/) 和 Apollo Automation，可以创建获得 Open Home Foundation 品牌授权的产品。基金会的[结构页面](https://www.openhomefoundation.org/structure/)解释了其运作方式。

## 商标与许可

该标志是商标，归 Open Home Foundation 所有。未经基金会书面许可，不得将其用于商业用途。商业用途指任何旨在营销或推广待售产品、软件或服务的行为。如需申请，请发送电子邮件至 [partner@openhomefoundation.org](mailto:partner@openhomefoundation.org)。

home-assistant.io 的[服务条款](https://www.home-assistant.io/tos/)将 Home Assistant 的名称和标志列为商标，并声明使用该网站并不授予使用它们的权利。

运营关于 Home Assistant 的粉丝账号、群组或频道？请在其名称或描述中明确说明它不是官方账号，以免有人误认为是官方账号。参见[社交媒体帮助](/community/guides/social-media/)。

### Works with Home Assistant

通过 [Works with Home Assistant](https://works-with.home-assistant.io/) 认证的设备制造商拥有自己的[徽章和品牌指南](https://works-with.home-assistant.io/resources/badge-and-brand-guidelines/)。这些指南仅适用于已认证的合作伙伴。例如，合作伙伴可以说某设备是 "Certified by the Works with Home Assistant program"，但不能说它是 "Recommended by Home Assistant" 或 "Home Assistant product"。

## 标志

标志是带有天线的蓝色房子。每个部分都有其含义：

![Home Assistant 标志：一座蓝色的房子，里面有一根白色天线，旁边是深色文字的 Home Assistant 字样](./logo.png)

- **蓝色**给人稳定和不可或缺的感觉。明亮的天蓝色充满喜悦、清晰且无云。
- **房子**代表家，简化为其最具标志性的形状：一座带斜屋顶的正交房子，没有山墙，也没有烟囱。
- **天线**是旧标志中最易识别的部分。有人把它看作一棵树、一组节点或一块电路板。它代表着智能、互联且常青生长的技术。

从[素材仓库](https://github.com/home-assistant/assets/tree/master/logo)下载标志的所有版本。

## 布局

![四种布局变体：水平布局的标志图形与文字标志、仅标志图形、垂直布局的标志图形与文字标志，以及使用较小标志图形的垂直布局](./logo-layout-variants.png)

标志有四种布局：

- **文字标志，水平**：默认布局。它提供了最清晰的上下文，因此在需要介绍 Home Assistant 时请使用它。
- **标志图形**：仅房子图形，用于显然是指 Home Assistant 标志的场合，例如应用内部。标志图形可以不带文字标志使用，但文字标志绝不能脱离标志图形单独使用。
- **文字标志，垂直**：用于宽高比低于 4:3 的空间，例如衣服上的方形位置。
- **文字标志，垂直并带小标志图形**：当 Home Assistant 与相关项目并列出现时使用，例如语音管道示意图中。

## 颜色与背景

- **浅色背景**：使用彩色版本配深色文字。这是默认设置。
- **深色背景**，例如深色主题中的页面：使用彩色版本配浅色文字。
- **深色或摄影背景**：浅色单色版本也可以。
- **浅色或摄影背景**：使用彩色版本，不要使用单色版本。
- **无法使用颜色时**，例如印刷品：使用单色版本。

标志只能与黑色、白色以及非双色调摄影搭配使用。

## 禁止事项

- 不要将标志图形放入方形、彩色形状或任何其他容器中。唯一的例外是其他公司的应用市场有此要求时，例如 iOS 应用图标。
- 不要添加投影。如果标志在背景上难以辨认，请更换背景以增加对比度。只有在万不得已时，才可使用重度模糊的投影。
- 不要使用描边版本。此标志没有描边版本。请改用单色版本。

## 留白

给标志留出空间。在标志周围保留至少标志图形高度四分之一的净空。

![水平标志的构造网格，其间距以标志图形的部分来度量，文字标志沿基线与房子内边框对齐](./logo-exclusion-zone.png)

## 动画

静态标志是默认形式。动画版本仅用作引导，例如视频开头或加载画面。

带声音的版本只应在人们预期有声音的场合使用，例如视频开头。切勿在界面中使用，例如加载画面。不要重复播放动画。

## 小尺寸

针对非常小的空间（约 16 x 16 dp）有专门的迷你版本：网站的 favicon、Android 上的通知图标，或 macOS 的菜单栏图标。

## 规则的归属

本页面包含 Home Assistant 的标志指南。它取代了 design.home-assistant.io 上的标志页面。如需建议修改，请在 [UX design discussions](https://github.com/OpenHomeFoundation/ux-design/discussions) 中发起讨论，或向[本网站](https://github.com/home-assistant/contributors.home-assistant.io)提交 pull request。
