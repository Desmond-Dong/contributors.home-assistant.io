品牌不仅仅是一个标志和一种语气。Home Assistant 的品牌始于这个项目所代表的东西。它的个性、语气和视觉设计都在表达同一件事：一个属于居住者的智能家居。

## 开放之家（Open Home）

开放之家是 Home Assistant 背后对智能家居的愿景。它定义了项目中每一个决策的核心价值观。这些价值观贯穿于架构、许可协议、社区以及其他一切之中。

拥有 Home Assistant 的[开放之家基金会（Open Home Foundation）](https://www.openhomefoundation.org/)用三个词概括它：隐私、选择和可持续性。

### 隐私

你的家应该是你的安全空间：一个你可以做自己的地方，无需为了不让算法对你的行为进行归类而改变自己的行为方式。对于开放之家来说，隐私意味着设备在本地工作。当你开灯或调节恒温器时，不需要让其他任何人知道。

产品可以提供云连接，但它应该是额外的、可选加入的功能。

### 选择

你家里的设备会收集关于它们自身及其周围环境的数据。那是你的数据。供应商不应限制你对这些数据的访问，也不应限制你的设备与家中其他设备的协同工作方式。

对于开放之家来说，选择意味着设备通过本地 API 提供其数据。这避免了供应商锁定，让人们可以用来自不同制造商的设备来构建自己的智能家居。

### 可持续性

科技公司擅长推出新产品，而让它们持续工作却常常是事后才考虑的事情：供应商停止支持某个设备，功能就会损坏，或者设备完全停止工作。家里的设备越多，这一点就越重要。任何人都不应该因为制造商转向了新方向，就每隔几年把所有东西重新买一遍。

对于开放之家来说，这意味着设备的设计和制造要保证持续工作。不只是今年，而是未来十年。

## 这些价值观对品牌意味着什么

这些价值观是品牌之所以呈现这种语气的原因。一个把人们的隐私和选择放在首位的项目，也不能居高临下地说话、隐藏局限性，或者用言辞把用户锁住。这正是[品牌个性](/brand/personality/)的来源：热情、坦率、乐于助人、慷慨和独立。

这些价值观也以各自的方式塑造着项目的其他方面：

- [我们的原则](/start/principles/)：这些价值观如何体现在我们的协作方式中
- [架构原则](/architecture/principles/)：它们对代码意味着什么
- [设计原则](/design/principles/)：它们对界面意味着什么

## Home Assistant 的由来

- **2013 年**：Paulus Schoutsen 于 9 月开始将 Home Assistant 作为一个 Python 应用程序开发，并于 11 月在 GitHub 上发布。
- **2017 年**：7 月，Hass.io——一个带有 Supervisor 的托管操作系统，可以安装、备份和更新 Home Assistant——让它更容易在 Raspberry Pi 等单板计算机上运行。12 月，[Home Assistant Cloud](https://www.home-assistant.io/blog/2017/12/17/introducing-home-assistant-cloud/) 作为免费公测版发布，Amazon Alexa 是它的第一个服务。
- **2018 年**：4 月，[Google Assistant 支持](https://www.home-assistant.io/blog/2018/04/24/launch-google-assistant-support/)紧随其后，仍处于免费测试阶段。9 月，Home Assistant 的创始人和核心贡献者创立了 Nabu Casa，从那时起[以订阅方式运营 Home Assistant Cloud](https://www.home-assistant.io/blog/2018/09/17/thinking-big/)。
- **2019 年**：3 月，Home Assistant Cloud 为你的 Home Assistant 添加了[安全的远程访问](https://www.home-assistant.io/blog/2019/03/20/release-90/)功能。
- **2020 年**：1 月，为了更容易区分各个部分，名称发生了变化。Python 应用程序更名为 Home Assistant Core。包含操作系统和 Supervisor 的完整套件则称为 Home Assistant。
- **2024 年**：Home Assistant 和其他项目被移交给非营利组织开放之家基金会。
- **2025 年**：所有参与基金会项目工作的人员从 Nabu Casa 转入开放之家基金会。Nabu Casa 继续作为基金会的商业合作伙伴。
- **2026 年**：Home Assistant Cloud 更名为 [Home Assistant Link](https://www.home-assistant.io/blog/2026/10/02/big-tech-ruined-the-cloud-so-were-renaming-ours/)。

[项目的组织方式](/start/organization/)介绍了如今基金会、其合作伙伴和贡献者是如何协作的。
