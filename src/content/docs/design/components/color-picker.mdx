## 概述

颜色选择器是一个圆形色轮。角度决定色相（hue），与中心的距离决定饱和度（saturation）：中心为白色，边缘为全彩。用户可以拖动标记，或点击色轮上的某个位置直接跳转过去。

在支持颜色的灯的更多信息对话框中可以找到它。在那里，它与其他几个控件一起出现：

- 一个小的取色器按钮，可打开浏览器或操作系统的原生颜色选择器，供想要输入精确颜色的用户使用。
- 用于颜色亮度和白色通道的滑块（适用于具备这些功能的灯）。色轮会跟随这些滑块，因此它显示的是灯光实际会呈现的颜色。

## 何时使用

在以下情况下使用色轮：

- 通过肉眼挑选颜色，例如灯光的颜色。它快速且对触屏友好。

在以下情况下不要使用色轮：

- 单独用于输入精确的颜色。色轮并不精确。当精确值很重要时，请在旁边提供其他输入方式，就像更多信息对话框在色轮旁边提供原生颜色选择器那样。
- 用于必须可以通过键盘操作的颜色输入，且旁边没有其他输入方式。色轮只响应指针操作。

## 结构

1. **色轮**：圆形画布，周围环绕所有色相，从中心的白色到边缘的全彩
2. **标记**：一个填充了所选颜色的圆，带有白色轮廓和阴影。没有值时会隐藏。

## 变体

色轮没有变体。变化的是它的绘制方式。

### 亮度和白色通道

色轮以全亮度绘制颜色。它可以整体调暗，以匹配用户为颜色选择的亮度。

对于带白色通道的灯，例如单个白色通道，或冷白和暖白，色轮会将白色混入其颜色中，以显示灯光的实际效果。

这些只会改变色轮的外观。所选的值仍然是色相和饱和度。

## 行为

- **拖动**：拖动时，标记会变大，以便在指针下保持可见。使用鼠标或触控笔时，它会放大到 1.5 倍。在触摸屏上，它会放大到 2.5 倍，并向上移动一点，以免被手指遮挡。
- **点击**：点击色轮会将标记移动到该位置并选中该颜色。
- **释放**：拖动结束时，标记会以动画恢复到正常大小，并选中该颜色。当浏览器取消拖动时，标记会回到原来的位置。
- **禁用**：禁用的色轮会忽略拖动和点击。它的外观与启用时相同。
- **无值**：没有值时，标记会隐藏。

色轮没有悬停或聚焦状态。

## 规格说明

色轮填满其容器，标记随其缩放。以下标记尺寸以色轮的坐标为单位，色轮默认宽度为 400 个单位。

| 属性 | 值 | Token |
| --- | --- | --- |
| 色轮形状 | 圆形 | `--ha-border-radius-circle` (50%) |
| 标记半径 | 16 个单位 | 无 |
| 标记轮廓 | 2 个单位，白色 | 无 |
| 标记阴影 | 两个投影：向下 1 个单位、模糊 2 个单位、30% 黑色，以及向下 1 个单位、模糊 3 个单位、15% 黑色 | 无 |
| 拖动时标记的缩放 | 鼠标或触控笔为 1.5，触摸为 2.5 | 无 |
| 触摸拖动时标记的偏移 | 向上偏移色轮尺寸的 1/16 | 无 |
| 标记动画 | 大小和颜色 100ms，位置 200ms，ease-in-out。拖动时关闭。 | 无 |
| 在更多信息对话框中的尺寸 | 屏幕高度的 45%，介于 200px 和 320px 之间 | 无 |

## 无障碍

### 键盘

色轮只响应指针操作：鼠标、触控笔或手指。它不获取焦点，也没有键盘交互。请将它与用户可以通过键盘操作的输入方式配对使用，例如更多信息对话框在色轮旁边提供的原生颜色选择器。

### 可见性

标记是所选颜色，带有白色轮廓和阴影，因此在色轮的明亮和深色部分都能保持可见。

### 屏幕阅读器

屏幕阅读器无法从色轮获取任何信息。旁边的输入方式才是访问途径。

### 在代码中

色轮是一个画布，上面有一个 SVG 标记。它没有供辅助技术使用的 role、名称或值。

## 代码实现

该元素是 `<ha-hs-color-picker>`。

```html
<ha-hs-color-picker value="[32, 0.6]"></ha-hs-color-picker>
```

色轮会填满其容器，因此需要为其指定尺寸。在更多信息对话框中，它占屏幕高度的 45%，介于 200 和 320 像素之间。

```css
ha-hs-color-picker {
  height: 45vh;
  max-height: 320px;
  min-height: 200px;
}
```

### 属性（Attributes）

- `value`：颜色，以数组形式表示色相（角度，`0` 到 `359`）和饱和度（`0` 到 `1`）。例如 `[32, 0.6]`。没有值时，标记会隐藏。
- `wv`：RGBW 灯的白色通道，从 `0` 到 `255`。
- `cw` 和 `ww`：RGBWW 灯的冷白和暖白通道，从 `0` 到 `255`。
- `disabled`：忽略拖动和点击。

### 特性（Properties）

这些只能作为特性设置：

- `colorBrightness`：色轮绘制时的亮度，从 `0` 到 `255`。默认为 `255`。
- `minKelvin` 和 `maxKelvin`：灯的色温范围。用于将冷白和暖白混入颜色中。
- `renderSize`：色轮的分辨率，以像素为单位。默认为 `400`。这不是屏幕上的尺寸。

### 事件

- `value-changed`：颜色被选中时触发，即用户松开或点击时。`detail.value` 是新的 `[hue, saturation]`。
- `cursor-moved`：拖动时标记移动。`detail.value` 是标记下的颜色，拖动结束时为 `undefined`。用它可以在拖动时预览颜色，而无需将每一步都发送到灯。

色轮会移动其标记，但不会更新自身的 `value` 特性。请从事件中读取新颜色。
