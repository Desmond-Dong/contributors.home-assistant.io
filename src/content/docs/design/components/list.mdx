## 概述

列表显示一组相似的内容，供人们浏览、选择或打开：用于登录的提供方、菜单选项、某个区域（area）中的设备。每一行的结构都相同，因此视线可以沿着左边缘快速找到所需内容。

> [!NOTE]
> `ha-list` 和 `ha-list-item` 是较旧的列表，基于 Material Web Components 构建。前端正在迁移到一套更新的列表组件：`ha-list-base`、`ha-list-item-base`、`ha-list-item-button`、`ha-list-selectable` 和 `ha-list-nav`。前端中的许多列表已经在使用它们。对于新代码，请使用新组件族：参见本页末尾的[新列表组件族](#the-new-list-family)。本页大部分内容介绍的是较旧的列表，因为仍有不少界面在使用它。

## 何时使用

在以下情况使用列表：

- 一组相似的内容，供人们浏览、选择或打开
- 导航到下一层级，每行末尾带一个箭头图标
- 仅显示信息的行，例如一个值或一条消息

不要在以下情况使用列表：

- 针对单个项目的操作。请使用[下拉菜单](/design/components/dropdown/)。
- 从少数几个需要解释的选项中选择一个。请使用[选择框](/design/components/select-box/)。
- 人们需要展开和收起的内容。请使用[折叠面板](/design/components/expansion-panel/)。

## 结构剖析

1. **列表**：容器，顶部和底部各有 8px 的内边距
2. **行**：列表中的一个项目
3. **图形（Graphic）**：可选，行开头的图标、头像或控件
4. **第一行**：该行的主要文本
5. **第二行**：可选，第一行下方的简短细节
6. **Meta**：可选，末尾的内容，例如箭头图标或简短的值

## 变体

### 行

以文本为主，只添加有助于人们识别该行的内容：

- 开头的一个**图标**。
- 一个**第二行**，用于简短的细节，例如状态或描述。
- **末尾**的内容，例如当该行会打开某些内容时的箭头图标，或一个简短的值。

### 图形尺寸

行会在开头为其图形预留空间，尺寸可以是以下之一：图标、头像（圆形图片）、中等或大尺寸图片，或复选框之类的控件。

### 仅显示信息的行

选中时不执行任何操作的行，例如仅显示一个值或一条消息的行，可以设为非交互式。此时它没有涟漪效果，也不会获得键盘焦点。

## 行为

- **悬停与按下**：可交互的行会显示涟漪效果。除非主题设置了其他颜色，否则为黑色。深色主题将其设为浅灰色。已激活的行的涟漪使用主色。
- **焦点**：同一时间只有一行处于 Tab 键序中。方向键在行之间移动焦点。
- **激活**：在行可被激活的列表中，被选中的行会获得 12% 不透明度的主色调，其图形会变为主色。
- **禁用**：文本变为禁用文本颜色，且该行无法被选中。
- **长文本**：第一行放不下时会以省略号截断。第二行也会被截断，除非该行允许换行。此时行会随之变高。

## 无障碍

### 键盘

| 按键 | 操作 |
| --- | --- |
| <kbd>Tab</kbd> | 将焦点移入列表中的一行，并可再次移出。 |
| <kbd>Arrow down</kbd> 和 <kbd>Arrow up</kbd> | 将焦点移到下一行或上一行。列表可以让焦点从最后一行循环到第一行，反之亦然。 |
| <kbd>Home</kbd> 和 <kbd>End</kbd> | 将焦点移到第一行或最后一行。 |
| <kbd>Enter</kbd> 或 <kbd>Space</kbd> | 激活获得焦点的行。 |

### 焦点

同一时间只有一行处于 Tab 键序中。方向键在行之间移动焦点。

### 目标尺寸

行的高度至少为 48px，宽度与列表相同。

### 屏幕阅读器

默认情况下，屏幕阅读器不会获得列表结构：列表及其行没有 role，因此它只会听到各行的文本。禁用的行会被播报为已禁用。可以在代码中为列表设置 role 和名称，见下文。

### 在代码中

- 列表及其行默认没有 role。在列表上设置 `innerRole`，为行设置 `itemRoles`，例如 `listbox` 和 `option`，并用 `innerAriaLabel` 设置列表的名称。
- 禁用的行带有 `aria-disabled="true"`。
- 当 role 为 `option` 时，被选中的行带有 `aria-selected="true"`。
- 带有 `noninteractive` 的行无法获得焦点。

## 代码实现

该元素是 `<ha-list>`，其行为 `<ha-list-item>`。两者都继承自 [Material Web Components list](https://github.com/material-components/material-web/tree/mwc/packages/list)。

```html
<ha-list>
  <ha-list-item graphic="icon" twoline hasMeta>
    <ha-svg-icon slot="graphic" path="..."></ha-svg-icon>
    Network
    <span slot="secondary">Connected over Wi-Fi</span>
    <ha-svg-icon slot="meta" path="..."></ha-svg-icon>
  </ha-list-item>
</ha-list>
```

HTML 中属性名不区分大小写，因此 `hasMeta` 和 `hasmeta` 是相同的。

### ha-list 的属性

- `activatable`：将被选中的行显示为已激活状态。
- `multi`：允许选中多行。
- `wrapFocus`：方向键从最后一行循环到第一行，反之亦然。
- `rootTabbable`：使列表本身可聚焦，而不是第一行。
- `noninteractive`：关闭整个列表的选择和键盘导航。
- `innerRole` 和 `innerAriaLabel`：内部列表元素的 role 和无障碍名称。
- `itemRoles`：赋予每一行的 role，例如 `option`。

### ha-list-item 的属性

- `graphic`：为 `graphic` 插槽中的内容预留空间。可为 `icon`、`avatar`、`medium`、`large` 或 `control`。
- `twoline`：将 `secondary` 插槽显示为第二行。
- `multiline-secondary`：让第二行换行，而不是截断。
- `hasMeta`：在末尾显示 `meta` 插槽。
- `noninteractive`：该行无法被选中或聚焦。
- `disabled`：禁用该行。
- `selected` 和 `activated`：选中状态。
- `value`：标识该行的值。

### ha-list-item 的插槽

- 默认：第一行文本。
- `secondary`：第二行，需设置 `twoline`。
- `graphic`：开头的图标、头像或控件，需设置 `graphic`。
- `meta`：末尾的内容，需设置 `hasMeta`。

### 事件

- `ha-list` 上的 `action`：某一行被激活。`detail.index` 是该行的索引。
- `ha-list` 上的 `selected`：选择发生了变化。`detail.index` 是被选中的索引，使用 `multi` 时为一组索引。
- `ha-list-item` 上的 `request-selected`：该行请求被选中或取消选中。`detail.selected` 是新状态，`detail.source` 说明它来自 `interaction` 还是 `property` 变化。

### 样式

- `--mdc-list-side-padding`：行两侧的内边距。默认为 `20px`。
- `--mdc-list-side-padding-left` 和 `--mdc-list-side-padding-right`：单侧的内边距。
- `--mdc-list-item-graphic-margin`：图形与文本之间的间距。
- `--mdc-list-item-meta-display`：meta 插槽的 display。

## 新列表组件族

新列表从一开始就具备无障碍和键盘友好特性。根据列表的含义选择容器，再根据行的行为选择项目。它们尚未作为本站的实时组件提供，因此没有演示。

### 容器

- `<ha-list-base>`：普通列表，role 为 `list`。方向键在行之间移动焦点，<kbd>Home</kbd> 和 <kbd>End</kbd> 跳转到第一个和最后一个可用的行，<kbd>Page up</kbd> 和 <kbd>Page down</kbd> 翻页，<kbd>Enter</kbd> 或 <kbd>Space</kbd> 激活获得焦点的行。同一时间只有一行处于 Tab 键序中。
- `<ha-list-selectable>`：供人们选择的列表，role 为 `listbox`。其行为 `<ha-list-item-option>`。设置 `multi` 以允许多选。
- `<ha-list-nav>`：链接列表，包裹在 `<nav>` 地标中。其行为带有 `href` 的 `<ha-list-item-button>`。使用 `aria-label` 为地标命名。

容器的属性：

- `wrap-focus`：方向键在两端循环。
- `virtual-focus`：焦点保持在列表之外，例如选择器的搜索框中。列表用 `active` 标记键盘指向的行，并将其滚动到可视区域。获得焦点的元素通过 `moveActiveItem()` 移动它。
- `aria-label`：无障碍名称。
- `multi`：仅用于 `ha-list-selectable`，允许选择多个选项。

事件：

- `ha-list-activated`：在获得焦点的行上按下 <kbd>Enter</kbd> 或 <kbd>Space</kbd>。`detail` 包含 `index` 和 `item`。
- `ha-list-item-selected` 和 `ha-list-item-deselected`：在 `ha-list-selectable` 上，某个选项被选中或取消选中。`detail` 是该选项的索引。取消选中仅在 `multi` 时触发。

样式：`--ha-list-gap` 设置行之间的间距，`--ha-list-padding` 设置列表四周的内边距。两者默认均为 `0`。

### 项目

每个项目都具有相同的行布局，包含以下插槽和属性：

- `start`：起始部分，例如图标或头像。
- `end`：末尾部分，例如一个值或箭头图标。
- `headline` 和 `supporting-text`：第一行和第二行，可作为属性或插槽。
- `content`：替换整个中间部分。
- `disabled`：使该行变暗并阻止指针操作。

这些项目：

- `<ha-list-item-base>`：仅显示信息的行，role 为 `listitem`。设置 `interactive` 可将其纳入列表的键盘导航但不执行操作，例如可供排序的行。
- `<ha-list-item-button>`：执行某种操作的行。带有 `href` 时渲染为链接，否则渲染为按钮。整行都是点击目标。
- `<ha-list-item-option>`：可供选择的行，带有 role `option` 和 `aria-selected`。选择状态由列表管理。使用 `appearance="checkbox"` 时会显示一个复选框，通过 `selection-position` 放在 `start` 或 `end`。默认外观 `line` 会高亮被选中的行。

行的样式：

- `--ha-row-item-min-height`：行的最小高度。默认为 `48px`。
- `--ha-row-item-padding-block`、`--ha-row-item-padding-inline` 和 `--ha-row-item-gap`：行的内边距，以及其各部分之间的间距。
- `--ha-list-item-focus-background` 和 `--ha-list-item-active-background`：键盘焦点时的背景，以及 `active` 行的背景。
- `--ha-list-item-selected-background`：被选中选项的背景，需使用 `appearance="line"`。
