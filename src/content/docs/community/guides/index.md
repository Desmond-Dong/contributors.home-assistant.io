每篇指南介绍一种帮助社区的方式。请选择适合你时间和技能的那一篇。

- [欢迎新用户](/community/guides/welcome-newcomers/）：帮助刚安装 Home Assistant 的人感到宾至如归。
- [审核机制如何运作](/community/guides/moderation/）：版主（moderator）的职责，以及有人违反规则时他们会采取的步骤。
- [举报问题](/community/guides/reporting/）：当有人违反行为准则，或有人感到不安全时该怎么做。
- [组织线下聚会](/community/guides/meetups/）：把你所在城市的智能家居爱好者聚集起来。
- [在社交媒体上提供帮助](/community/guides/social-media/）：帮助 Home Assistant 触达更多人。
