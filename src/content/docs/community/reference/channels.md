Home Assistant 社区分布在几个不同的地方。每个地方都有自己的特色，也有自己的管理员。[行为准则](https://www.home-assistant.io/code_of_conduct/)适用于所有这些场所。

## 社区论坛

[社区论坛](https://community.home-assistant.io/)是规模最大、历史最悠久的求助场所。问题和答案会长期保留，并且易于搜索，因此一个已解决的帖子可以持续帮助人们多年。论坛还有用于分享项目、蓝图（blueprint）和社区指南的版块，以及一个 **Social** 版块，用于发布聚会信息。

适合在论坛使用的情况：需要一些时间才能解答的问题、分享你构建的作品，以及任何其他人日后应该能够找到的内容。

## Discord

[Home Assistant Discord 服务器](https://www.home-assistant.io/join-chat)用于实时交流。它快速而随意，非常适合快速提问或闲聊。贡献者也使用它：这里有用于开发和设计的频道，还有一个供测试下一版本的人使用的 **#beta** 频道。

Discord 上的内容日后很难再找到。当你解决了其他人可能也会遇到的问题时，请考虑同时发布到论坛上。

## Reddit

[r/homeassistant](https://www.reddit.com/r/homeassistant/) 子版块是许多人分享自己的配置、仪表盘（dashboard）和经历，并寻求建议的地方。它由自己的管理员管理，有自己的规则。

## Facebook

[Home Assistant Facebook 主页](https://www.facebook.com/homeassistantio)分享新闻。还有一个 [Facebook 群组](https://www.facebook.com/groups/HomeAssistant/)，人们可以在那里寻求和提供帮助。

## 社交媒体

官方账号分享新闻、版本发布以及来自社区的精彩内容。完整列表请参阅[社交媒体帮助](/community/guides/social-media/)。

## 新闻通讯

[Open Home Foundation 新闻通讯](https://newsletter.openhomefoundation.org/)将 Home Assistant 以及基金会其他项目的新闻发送到你的收件箱。

## 聚会和活动

本地聚会列在 [Luma 上的 Home Assistant Meetups 日历](https://luma.com/homeassistant)以及[社区页面](https://www.home-assistant.io/community/)的地图上。请参阅[举办聚会](/community/guides/meetups/)。

## 地区社区

还有其他语言和地区的社区。[社区页面](https://www.home-assistant.io/community/)列出了团队所了解的社区（并非详尽列表），例如法语论坛、德语 Discord 服务器和论坛，以及澳大利亚和新西兰、日本、挪威等地的群组。你的社区不在列表中？请发送电子邮件至 [community@openhomefoundation.org](mailto:community@openhomefoundation.org)。

## GitHub

GitHub 是代码和文档所在的地方，也是报告缺陷（bug）的地方。它不是支持渠道：关于使用 Home Assistant 的问题应发布在论坛或 Discord 上。功能请求请提交到[功能请求讨论区](https://github.com/home-assistant/feature-requests/discussions)，而不是问题跟踪器。
