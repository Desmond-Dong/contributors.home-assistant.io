每篇指南涵盖一个任务。前三篇不需要代码，只需要一些好奇心。最后一篇面向集成开发者。

- [使用公开数据](/data/guides/public-data/)：下载分析数据集，并构建你自己的图表。
- [探索你自己的数据](/data/guides/explore-your-data/)：将 JupyterLab 连接到你的 Home Assistant 数据库，并运行你的第一份报告。
- [查询数据库](/data/guides/query-the-database/)：针对状态（state）、事件（event）和上下文（context）的 SQL 查询示例。
- [集成中的分析](/data/guides/integration-analytics/)：你的集成如何出现在分析中，以及如何将设备（device）或实体（entity）排除在外。
