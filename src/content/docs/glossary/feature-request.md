功能请求应提交到[功能请求讨论区](https://github.com/orgs/home-assistant/discussions)，而不是提交到代码仓库的 issue：issue 用于报告问题。[Open Home Foundation](/glossary/open-home-foundation/) 的产品团队会关注这些请求，并将其中一些转化为[路线图机会](/glossary/opportunity/)。
