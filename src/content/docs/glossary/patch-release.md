版本号中的最后一个数字表示补丁版本（patch release）的序号：2026.10.1 是 2026.10.0 之后的第一个补丁版本。修复内容会先合并到 `dev` 分支，然后再挑选进入下一个补丁版本。每个补丁版本在当月的发布说明中都有自己独立的章节。参见 [Get a fix into a patch release](/releases/guides/patch-releases/)。
