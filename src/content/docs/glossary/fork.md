你无法直接修改 Home Assistant 的仓库。作为替代，你可以修改自己的 fork（分叉），然后发起 pull request（拉取请求）向原始仓库提议该修改。当你在 GitHub 上编辑一个你没有写入权限的仓库中的文件时，GitHub 会主动为你创建 fork。
