应用（App）以前被称为加载项（add-on）。代码中仍然使用旧名称，例如在 Supervisor API 中、在 `config.yaml` 的键中，以及在像 home-assistant/addons 这样的仓库名称中。在文字中请使用“应用”。

不要与手机和电脑上的[伴侣应用（companion apps）](/glossary/companion-app/)混淆。
