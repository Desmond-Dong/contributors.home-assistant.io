可以把仓库（repository）想象成一个带有记忆的项目文件夹。Home Assistant 的每个部分都有自己的仓库：Home Assistant Core 位于 `home-assistant/core`，文档位于 `home-assistant/home-assistant.io`，界面位于 `home-assistant/frontend`。每个仓库都有自己的议题（issue）、拉取请求（pull request）和维护者。

刚接触 GitHub？[Use GitHub, without being a developer](/start/github/) 解释了你在那里会遇到的各种术语。
