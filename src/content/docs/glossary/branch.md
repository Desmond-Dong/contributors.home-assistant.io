每个拉取请求（pull request）都来自一个分支（branch）。每次更改都应使用一个新分支，这样每个拉取请求就只涉及一件事。拉取请求所要合入的分支称为其基础分支（base branch），例如 Home Assistant Core 的 `dev`，或文档网站的 `current`。
