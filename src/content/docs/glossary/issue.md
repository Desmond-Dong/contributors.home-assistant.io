每个仓库都有自己的 issue（议题）。在 Home Assistant 中，issue 用于报告问题：例如 bug，或文档中错误的页面。功能建议请提交到[功能请求讨论区](https://github.com/orgs/home-assistant/discussions)，支持方面的问题请前往[社区论坛](https://community.home-assistant.io/)。参见[我们的交流渠道](/start/where-we-talk/)。

issue 与修复问题（repair issue）不同，后者是 Home Assistant 向其用户展示的。那是一种[修复（repair）](/glossary/repair/)。
