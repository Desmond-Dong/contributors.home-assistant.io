前端（frontend）是用户在浏览器中看到的一切内容：仪表盘（dashboard）、设置、自动化（automation）编辑器以及每一个对话框。[伴侣应用（companion apps）](/glossary/companion-app/)显示的也是同一个前端。

它通过 WebSocket 连接与 Home Assistant Core 通信。
