Home Assistant OS 自带 Supervisor、应用和备份。Home Assistant Container 则在用户自行管理的容器中运行 Core。

Home Assistant Core 和 Home Assistant Supervised 安装方式（即用户自行安装各个组件）自 Home Assistant 2025.12 起不再受支持。
