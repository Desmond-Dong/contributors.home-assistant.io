Core 运行事件循环（event loop）、状态机（state machine）、注册表（registries）以及每一个集成（integration）。无论周围运行着什么，每个 Home Assistant 安装都会运行 Core。

当人们在对话中说 "core" 时，通常指的是这个仓库以及为它工作的人。在文字中，首次出现时应写作 Home Assistant Core。
