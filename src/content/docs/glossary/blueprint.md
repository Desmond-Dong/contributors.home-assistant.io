这些空白就是输入项，每个输入项都可以有一个[选择器（selector）](/glossary/selector/)，这样用户界面就能为它显示合适的控件。

用户通过链接导入蓝图（blueprint），例如论坛帖子或 GitHub 上的文件，而不是通过[市场（Marketplace）](/glossary/marketplace/)。要编写和分享蓝图，请参阅市场部分的[蓝图](/marketplace/guides/blueprints/)指南。
