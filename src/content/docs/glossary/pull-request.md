拉取请求（pull request）从包含你更改的分支开始。自动检查会在其上运行，维护者或集成（integration）负责人会对其进行审查。草稿拉取请求（draft pull request）尚未准备好接受审查。

保持拉取请求小而专注于一件事。小的更改会被更快地审查和合并。
