每篇指南围绕发布中的一个任务展开。其中大多数不仅对负责发布的人重要，对任何提交拉取请求（pull request）的人都很重要。

- [发布说明与发布聚会](/releases/guides/release-notes/)：每月发布说明是如何完成的，以及你可以如何提供帮助。
- [记录向后不兼容的更改](/releases/guides/backward-incompatible-changes/)：告诉用户哪些内容会受影响、如何修复以及原因。
- [弃用某些内容](/releases/guides/deprecations/)：弃用政策，以及弃用信息如何进入发布说明。
- [将修复纳入补丁版本](/releases/guides/patch-releases/)：缺陷修复如何进入测试版和补丁版本。
